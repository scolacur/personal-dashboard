# [Acute Strategies] Add-idea button on the widget + "Save and add another" on the new-idea modal

**What shipped:** A "+ New idea" button on the generator face (works in both `variant="widget"`
and `variant="page"`) that opens `IdeaEditModal` in create mode, and a "Save and add another"
secondary action shown in create mode only. Form parsing/validation extracted to
`utils.parseIdeaForm` with unit tests.

**Worth remembering:** The non-obvious bit was ownership of closing the modal. `handleSave` in
`AcuteStrategiesGenerator.svelte` previously set `editingIdea = undefined` itself, which would
have slammed the modal shut even on the "add another" path. I moved the close decision into the
modal: `onSave` now only persists + refreshes the list, and the modal calls `onCancel()` after a
single save but resets its own form (and refocuses the textarea via `bind:this` + `tick()`) on
"add another". `isCreate` is derived from `idea == null`, which also drives the create-only
visibility of the secondary button. Error path keeps the entered text (never resets on failure).
