# [Dev Ops] Refine open-round form moves into the input dock (PD-841)

**What shipped:** In `apps/web/src/lib/TicketThread.svelte`, when a structured question round is
open its `RefineQuestionForm` now renders in the reply dock in place of the reply textarea, instead
of nested inside the agent's message bubble. The bubble keeps only the agent's prose; the folded
`turn-round-past` details still render for answered/superseded rounds. Park stays reachable while a
round is open. Added `.reply-open-round` / `.reply-round` SCSS so the form sits flush in the dock
and scrolls internally (`max-height: 360px`) rather than pushing the conversation out.

**Worth remembering:**
- `RefineMessage.round` is typed `RefineQuestionRound | undefined`, so passing `openRound.round` to
  the form needs a narrowing `{#if openRound.round}` guard — the old inline site narrowed it for free
  via `{#if m.round && ...}`. Without the guard svelte-check fails typecheck.
- Deleting the inline-form branch meant flipping `{:else if m.round}` to `{#if m.round && openRound?.id !== m.id}`
  so the folded past-round details do NOT also render on the currently-open round (only its prose shows).
- `.turn-round` base class is still used by `.turn-round-past`, so its styles stay live — not dead CSS.
- No vitest changes: TicketThread is a `.svelte` file (apps/web vitest can't import it) and the pure
  form logic in `refine-form-logic.ts` was untouched.
