# [Acute Strategies Generator] Import / Export the idea list as a text file

**What shipped:** Import (file-or-paste, one idea per line, batch type/tags, server+client
dedupe, preview count, one-transaction `POST .../ideas/import`) and Export (`acute-strategies.txt`,
one idea per line). Parsing/dedupe live in pure `import-export.ts` with unit tests. This run was a
**rework**: the feature was already implemented in commit 893d050; the PR had fallen into conflict
with main and only needed re-integration.

**Worth remembering:**
- The clone was a **shallow** checkout (`git rev-parse --is-shallow-repository` => true), so
  `git merge origin/main` failed with "refusing to merge unrelated histories". Fix:
  `git fetch --unshallow origin` first — then the merge base (8d95fb5) reappeared.
- The only real conflict was `IdeaList.svelte`. Main (PD-458) had moved "+ Add Idea" from the
  header to the **bottom** of the list and dropped the header-actions block. Resolved by placing
  Import/Export beside that bottom "+ Add Idea" in a new `.footer-actions` group (renamed the
  now-unused `.header-actions` SCSS and dropped `btn-add`'s full-width styling so the three
  buttons sit in a row).
