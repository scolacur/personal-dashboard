# [Acute Strategies Generator] Import / Export the idea list as a text file

**What shipped:** Batch text import (file picker or paste, one idea per line, whole-batch
type + tags, dedupe preview "N to add, M skipped") via a new `POST
/api/widgets/acute-strategies-generator/ideas/import` that dedupes case-insensitively
server-side and inserts in one transaction; plus a text export
(`acute-strategies.txt`, one idea per line, newlines collapsed to spaces so it round-trips).

**Worth remembering:**
- Pure parse/dedupe/serialise live in `apps/web/src/lib/acute-strategies-generator/import-export.ts`
  (web-tested, per ticket). The server re-dedupes in `store.ts#importIdeas` with the same
  `trim().toLowerCase()` key — deliberately duplicated rather than shared, since server widget
  code can't import from `apps/web` and the rule is two lines.
- Server `skipped = lines.length - created.length`, so blanks and duplicates both count as
  skipped. The client only ever sends trimmed non-blank lines (`parseLines`), so for the real
  UI flow `skipped` is exactly the duplicate count.
- All-or-nothing is a `better-sqlite3` `db.transaction()`; the store spec forces a rollback with
  a CHECK-constrained table rather than mocking.
- No schema change (`asg_ideas` already existed); `schema.ts` untouched as instructed.
