# [Infra] Publish the agent-worker image to GHCR on merge + gate apps/agent-worker/**

**What shipped:** A second job (`build-and-push-agent-worker`) in `.github/workflows/deploy.yml`
builds `ops/agent-worker/Dockerfile` (context = repo root) and pushes
`ghcr.io/scolacur/personal-dashboard-agent-worker:latest` + `:<short-sha>`, baking the real
`BUILD_SHA` (D-079/PD-528). Strengthened the existing `apps/agent-worker/**` sensitive-path
comment with the auto-deploy rationale + a PD-311 pointer.

**Worth remembering:** `apps/agent-worker/**` was ALREADY in `.github/sensitive-paths.txt` — it
was added by D-103 (PD-807, #460) which landed AFTER this ticket was written, as the
auto-promotion PR-time backstop. So the gate Done-When was already satisfied; I did not duplicate
the glob, I only augmented its comment. The image path uses `${{ github.repository }}-agent-worker`
(= `scolacur/personal-dashboard-agent-worker`), mirroring the app job's `${{ github.repository }}`.
Gave each build job a distinct `type=gha` cache scope (`scope=app` / `scope=agent-worker`) so the
two different Dockerfiles don't poison each other's cache. Build-arg is `BUILD_SHA`, NOT
`APP_VERSION` (the app job's arg) — the worker Dockerfile declares `ARG BUILD_SHA`.
