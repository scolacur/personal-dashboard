# [Audit] Per-project fan-out + per-project pause (auditEnabled) + confidence (PD-838 / robot/t1000)

**What shipped:** The Ticket Audit (`apps/agent-worker/src/jobs/audit`) now fans out over every
`audit_enabled` project with active tickets instead of auditing only the lowest-id one. Added the
`audit_enabled` column (`agent_projects`, `NOT NULL DEFAULT 1`) + `auditEnabled` on `AgentProject`
/ `CreateProjectInput`; `auditableProjects()` / `projectByKey()` queries; per-project try/catch so
one project's error/timeout is logged and skipped without aborting the run; `confidence`
(high|medium|low) emitted per finding and persisted; `counts.projects` = real number audited;
scope `single:<KEY>` audits just that project, else `scope='all'`.

**Worth remembering:**
- This slice DELIBERATELY changes the old error semantics. The old test "throws on an agent error
  so the run is retried" no longer holds — under fan-out a single project's agent error (`!reply.ok`
  or a thrown timeout) is logged and skipped (Done-When #3), so the run finishes `done`. I updated
  that test rather than weakening it. Tradeoff: a systemic error (billing/rate limit) that fails
  *every* project now closes the run `done` with zero findings rather than `error`-for-retry. The
  ticket's Done-When #3 explicitly asks for per-project resilience, so I followed it.
- A `single:<KEY>` run OVERRIDES the `audit_enabled` pause (explicit human request for that project),
  so `projectByKey` does not filter on the flag; only the `all` fan-out honours the pause.
- `finishRun` now persists `scope` via `COALESCE(?, scope)` so a run created with a scope keeps it
  and a full sweep records `'all'`.
- PD-910 usage accounting: turns/tokens are accumulated across the fan-out (turnsBase/tokensBase
  passed into each project's live-progress callback) so the running total doesn't reset per project.
- `kept firstProjectWithActiveTickets` (now unused by audit.ts) because its unit tests remain.
- `apps/web/src/routes/devops/copy-utils.spec.ts` builds a full `AgentProject` literal — had to add
  `auditEnabled` there too or web typecheck fails.
