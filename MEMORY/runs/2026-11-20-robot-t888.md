# [Habit Tracker] Log › By Habit calendar: week rows, month gutter, streak stats

**What shipped:** Evaluator-rework pass on the By Habit calendar PR. Replaced the hand-rolled
`.view-switch` button group in `LogView.svelte` with the shared `$lib/SegmentedToggle.svelte`

`onChange` receives the typed value — swap the `VIEWS` array key from `id` to `value` or the
generic `T extends string` won't line up. The 📅 deep-link button on Today rows was left as-is:
the Evaluator flagged it only for awareness; it's justified and recorded in D-102.
