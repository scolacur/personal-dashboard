# [Auto-queue] "Exclude from auto-queue" toggle on the Epic page and Epic card marker

**What shipped:** A frontend-only slice of D-103's exclusion layer: an "Exclude from auto-queue"
toggle on the Epic detail page (`AutoQueueToggle.svelte`) bound to `autoQueueExcluded` via the
generic `updateTicket` PATCH, and a "⛔ No auto-queue" marker on excluded Epic cards in the board's
Epic band (`EpicCard.svelte`). A visual fixture now seeds one excluded Epic.

**Worth remembering:** The whole backend half was already done by an earlier ticket in this Epic —
the `auto_queue_excluded` column, store mapping, the PATCH field in routes.ts (validated, no
isEpic check), and the shared `epic-not-excluded` eligibility criterion all existed. So this was
purely UI + fixture. Unlike BackfillToggle (which has its own dedicated POST route), the
auto-queue flag rides the generic `updateTicket` PATCH, so no new api.ts function was needed. The
toggle's checkbox is checked = excluded (natural for an "Exclude" label), which is the inverse of
BackfillToggle's checked = enabled.
