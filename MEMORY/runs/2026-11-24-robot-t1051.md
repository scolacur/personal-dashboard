# [Refine] Mark an open question round or pending proposal stale when a ticket it cites changes (PD-889) — Evaluator rework

**What shipped:** Added the missing `superseded` trigger test to `refine-stale.spec.ts`'s
'split / superseded' describe block (the Evaluator's one MUST-FIX test gap). The test drives a
Populate on an Epic with `supersedes: [member.displayId]`, which closes the member with
`closeReason: 'superseded'`, and asserts the citing session gets exactly one `refine_round_stale`
turn with `change: 'superseded'` and the matching message.

**Worth remembering:** The `superseded` trigger isn't reachable via a plain `updateTicket` status
change in a test — it only fires when `approveRefine` closes a superseded member (store.ts ~2631,
`closeReason: 'superseded'`). Reuse the setup pattern from `refine-supersedes.spec.ts`: an Epic +
member + a Populate decompose proposal naming the member in `supersedes`. `member.displayId` is
`string | null`, so a `satisfies RefineProposal` literal needs `member.displayId!` (sibling specs
use non-null assertions too).
