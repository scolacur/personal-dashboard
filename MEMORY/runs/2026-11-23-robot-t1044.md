# [Evaluator] Harden JSON extraction: pick the last top-level object with a valid verdict (string-aware)

**What shipped:** Rewrote `extractJson` in `apps/agent-worker/src/jobs/evaluate/verdict.ts`. It now
scans for every balanced top-level `{…}` candidate with a string-aware walk (tracks double-quoted
strings + backslash escapes), prefers fenced ```` ```json ```` blocks when present, and returns the
LAST candidate that `JSON.parse`s to an object with a valid `verdict`. Replaces the old
`indexOf('{')…lastIndexOf('}')` slice that a brace in the prose (e.g. `${...}` SQL) could corrupt.

**Worth remembering:** The null contract was preserved by moving the `isVerdict` check *into*
extraction — an object with an unknown verdict is skipped rather than returned, so `parseEvaluatorReport`
still returns null for it (D-076: null ≠ ship). `parseEvaluatorReport`'s own `isVerdict` guard is now
redundant but kept as a cheap belt-and-braces. No decision file needed — this is a straight
correctness fix matching the function's own existing doc-comment.
