# [bugfix] [Evaluator] A ticket range in a PR title (PD-859–PD-862) links only its endpoints — the middle tickets read as scope creep

**What shipped:** `linkedTickets` (apps/agent-worker/src/jobs/evaluate/all-prs.ts) now expands a same-prefix ticket range in the PR branch or title into every id in it before the per-id match, so a PR titled with a range (`PD-859–PD-862`, hyphen, `..`, "to", en/em dash) is judged against every ticket, not just the two endpoints. Capped at MAX_RANGE_IDS=20 (fall back to endpoints + warn), mixed-prefix pair left as two ids, non-existent middle ids dropped by `lookupTicket`.
