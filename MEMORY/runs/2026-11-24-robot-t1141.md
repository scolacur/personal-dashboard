# [Decisions] Ticket Suggestions — Evaluator leftovers at the round cap become a suggestion

**What shipped:** Rework of PR #568 addressing Evaluator feedback. Added timeline rendering for the
Ticket Suggestion lifecycle events (`suggestion_filed`/`approved`/`rejected`) in
`ActivityTimeline.svelte` — including the link to the created ticket on `suggestion_approved` that
the ticket's Done-When required — and fixed `rowTo()` in the store to read `row.source` (via
`isTicketSuggestionSource` with an `evaluator` fallback) instead of hardcoding it.

**Worth remembering:** `ActivityTimeline.svelte`'s `describe()`/`icon()` are inline in the `.svelte`
component so they aren't unit-testable (apps/web vitest can't import `.svelte`); the whole component
follows that pattern already, so these cases match it. The source-readback fix is a singleton enum
(`TICKET_SUGGESTION_SOURCES = ['evaluator']`) today, so the unknown value falls back to 'evaluator';
it's the "room to grow" path for a future Robot-filed source (D-119).
